Common Question

SageMaker Console looks different from the course videos - Why?

SageMaker periodically changes the workflow - this is a common issue (or benefit) with AWS Cloud.

When you launch a new instance, the current workflow no longer copies the SageMaker examples to your working folder

So, you may see a new Jupyter console that looks empty

To copy the SageMaker provided examples, you need to select the SageMaker Examples Tab from your notebook instance

NOTE: For the lectures in this course, I will primarily rely on notebooks that I distribute as part of the course. As you become familiar with SageMaker and want to try other examples, you can follow the below steps to try out SageMaker provided samples

Expand the section for example, Introduction to Amazon Algorithms

Select the example you want to try for example, DeepAR-Electricity.ipynb and choose Use


The selected example is now copied to your working area you can now use it like any other notebook file
